Aceternity UI (ui.aceternity.com) — 200+ copy-paste React + Tailwind + Framer Motion components, blocks, landing-page templates. Known for aurora backgrounds, sparkles, 3D cards, bento grids, timelines, scroll reveals, spotlight/parallax effects. Publishes a shadcn registry — install via shadcn CLI or copy code directly. Free tier (200+ components); premium blocks (100+) + templates (30+) behind $199 lifetime access.

Site: https://ui.aceternity.com/
Components: https://ui.aceternity.com/components

Same shadcn-CLI/TS/Tailwind/Framer-Motion pattern as [[reference-unlumen-ui]], [[reference-magic-ui]], [[reference-smooth-ui]]. Closest comparison is Magic UI — both skew landing-page/marketing visual effects; Aceternity leans more toward big hero/background effects (aurora, spotlight, 3D), Magic UI toward smaller composable widgets. Distinct from [[reference-retro-ui]] (aesthetic-only, not animation-focused).
