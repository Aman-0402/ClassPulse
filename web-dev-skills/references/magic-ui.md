Magic UI (magicui.design) — open-source component library for design engineers, 150+ animated components. Built with TypeScript, Next.js, Tailwind CSS, Framer Motion. Copy-paste philosophy like shadcn/ui (full code ownership, no extra deps). Geared toward landing pages / marketing UI (animated backgrounds, text effects, interactive cards, transitions, globes).

Install same as shadcn/ui: `pnpm dlx shadcn@latest add @magicui/<component>`.

Docs: https://magicui.design/docs
Site: https://magicui.design/

Same install pattern as [[reference-unlumen-ui]] (both are shadcn-registry libs, TS/Tailwind/Framer Motion) — Magic UI skews marketing/landing-page components, Unlumen UI skews general product UI. Both drop-in candidates for stacks already on shadcn/ui + Tailwind + Framer Motion (e.g. [[innolance-lms-fullstack]]).
