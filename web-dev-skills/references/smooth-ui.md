SmoothUI (smoothui.dev) — free open-source, 75+ animated React components (accordions, dropdowns, modals, text effects). Built with React, Tailwind CSS, Motion (Framer Motion). Shadcn/ui compatible: `npx shadcn@latest add <component>`, TypeScript, dark mode support, respects `prefers-reduced-motion`. MIT licensed.

Docs/repo: https://github.com/educlopez/smoothui
Site: https://smoothui.dev/

Same shadcn-CLI/TS/Tailwind/Motion pattern as [[reference-unlumen-ui]] and [[reference-magic-ui]] — SmoothUI skews general micro-interactions/UI polish (vs. Magic UI's marketing focus, Unlumen's product UI). Accessibility-conscious default (reduced-motion support) is the standout differentiator among the three.
