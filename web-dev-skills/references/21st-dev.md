21st.dev — largest React component registry/marketplace, "npm for design engineers." 12,000+ hand-crafted React + Tailwind CSS components, templates, shadcn themes by independent design engineers. Preview live, install with one command (shadcn-CLI style). Also ships AI-agent building blocks: agent templates, SDK with built-in UI/tools/memory/observability. Copy a component's prompt into Cursor/Claude Code/v0/Lovable to have the agent rebuild it in your codebase. Anyone can publish and keep authorship; template authors can sell. Founded 2024 (Sergey Bunas, Serafim Korablev), YC company.

Site: https://21st.dev/
Repo: https://github.com/serafimcloud/21st
Docs: https://help.21st.dev/

This is the marketplace/aggregator layer — [[reference-unlumen-ui]], [[reference-magic-ui]], [[reference-smooth-ui]], and [[reference-aceternity-ui]] all list/mirror their components on 21st.dev. Good first stop when browsing for a shadcn-compatible component before checking individual libraries.
