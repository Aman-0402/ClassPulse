When creating or editing a website, always account for SEO (Search Engine Optimization), AEO (Answer Engine Optimization — structured/direct-answer content for featured snippets and voice assistants), and GEO (Generative Engine Optimization — content structured to be cited well by AI answer engines like ChatGPT/Perplexity/AI Overviews).

**Why:** User explicitly asked this be remembered as a standing requirement for website work.

**How to apply:** For any website task (landing pages, marketing pages, public-facing docs), proactively include: semantic HTML + proper heading hierarchy, meta title/description, structured data (JSON-LD schema.org), clear/direct-answer content blocks (good for AEO/GEO), fast load/Core Web Vitals, sitemap/robots.txt, descriptive alt text, canonical URLs. Don't wait to be asked each time — bring it up during planning/brainstorming for new pages.
