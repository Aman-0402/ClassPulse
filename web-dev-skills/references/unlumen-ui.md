Unlumen UI (ui.unlumen.com) — curated React component library/registry. Built with TypeScript, Tailwind CSS, Motion (Framer Motion). Components install via the shadcn CLI, like other shadcn-registry libs. Free components + paid Pro tier. Awwwards Honorable Mention.

Docs/registry: https://github.com/leovvx/unlumen-ui-docs
Preview/copy components: https://21st.dev/@unlumen
Site: https://ui.unlumen.com/

Fits stacks already using shadcn/ui + Tailwind + Framer Motion (e.g. [[innolance-lms-fullstack]] project stack) — same install pattern as existing shadcn components, drop-in candidate for animated UI needs. See also [[reference-magic-ui]] (similar stack, marketing/landing-page focus).
