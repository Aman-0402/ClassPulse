`awesome-design-md` (github.com/VoltAgent/awesome-design-md) — curated collection of DESIGN.md files, each a plain-markdown design-system extraction of a real brand (Apple, Claude, etc.): colors, typography, spacing, component tokens, rules. Concept originated with Google Stitch. Drop one into a project; tell the AI agent "build this page to match" for on-brand UI generation.

Repo: https://github.com/VoltAgent/awesome-design-md
Individual example: https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md

Related/spinoff collections:
- `xjli360/awesome-design-md-ecommerce` — 1,632 e-commerce brand DESIGN.md files
- `Meliwat/awesome-ios-design-md` — 200 iOS-app DESIGN.md files (SwiftUI/Compose/Expo, incl. motion curves + haptics)
- `bergside/awesome-design-skills` — 67 DESIGN.md/SKILL.md files for agentic tools (Claude, Stitch, Codex, Cursor)
- `VoltAgent/awesome-claude-design` — 68 DESIGN.md inspirations specifically for Claude

Complements [[reference-design-taste-skill]]: design-taste gives generic anti-slop taste *rules*; a DESIGN.md gives a specific brand's concrete *tokens* to match. Use DESIGN.md when a task says "make it look like X"; use design-taste's rules always.
