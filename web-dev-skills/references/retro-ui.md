Retro UI (retroui.io) — component library for React sites, pixelated retro aesthetic. Stack: React, Tailwind CSS, TypeScript. Copy-paste style components (shadcn-like) rather than an npm package.

Site: https://retroui.io/
(Search also surfaces a formerly-same-named, now-rebranded "NeoBrutalism" library — https://neobrutalism.com/ — hard shadows/thick borders/high-contrast retro-brutalist style, and unrelated "retro-react" Win95/98-style lib on GitHub. Confirm which one the requester means if a task references "Retro UI" — several distinct libs share the name.)

Distinct from [[reference-unlumen-ui]], [[reference-magic-ui]], [[reference-smooth-ui]] — those three are shadcn-CLI/Framer-Motion animation-focused; Retro UI is a visual-aesthetic (pixel/retro) library, not primarily an animation library.
